# Spaceship Odyssey

A choose-your-own-adventure game that runs in the terminal. You're the captain of the Spaceship Odyssey: investigate a strange signal from a nebula, outrun or battle a mysterious wanderer, board an alien ship, and find one of several endings.

Each scene is its own function, and your choices decide which function runs next. That's how the story branches.

```bash
python3 terminal-game.py
```
